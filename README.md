## 🌟 Overview & Interpretation of the Theme

**Ghost in the Machine** is an atmospheric dual-mode tribute built for **Hacktoberfest Open-Source AI Challenge Week 4**. Falling between **Halloween (Oct 31)** and **Día de los Muertos (Nov 1–2)**, it bridges spooky cyber-folklore with heartfelt ancestral remembrance:

1. **NecroShell v3.13 (The Possessed Terminal & Séance)**: A retro CRT green-phosphor shell possessed by spirits of computing history (Ada Lovelace, Alan Turing, Grace Hopper, Dennis Ritchie, and Hedy Lamarr). Whispers eerie commentary on commands, glitched with real-time procedural audio synthesis.
2. **Altar de Recuerdos (The Living Ofrenda)**: A sacred Día de los Muertos candlelight sanctuary with floating marigold petal physics (cempasúchil), sugar skulls, and traditional papel picado festoons. Uses open-source AI to compose authentic *Calaveritas Literarias* (satirical folk rhymes) and sacred digital eulogies without sending sensitive family memories to corporate servers.
3. **The Phantom Investigator (IoT & Telemetry Weaver)**: Transforms midnight smart home sensor logs (motion in 0 lux, thermal plunges, electromagnetic flicker) into chilling paranormal case dossiers.
4. **Why Open Innovation Matters**: An interactive architectural breakdown demonstrating why open weights and local inference safeguard grief, resist power outages, cost \$0, and prevent corporate lock-in.

## 🕯️ Why Open Innovation Matters

In sensitive domains like **cultural mourning (Día de los Muertos)** and **creative folklore (Halloween)**, closed cloud APIs fail fundamentally:

- **Sacred Data Sanctity**: When you write memories of your departed grandmother or upload family lore, closed APIs store, tokenize, and train commercial advertising corpora on your grief. With our open-source AI architecture, **zero bytes ever leave your RAM**.
- **Storm & Outage Resilience**: Halloween storms regularly disrupt power grids and internet cables. Because GhostMachine runs on in-browser open-weight engines, the séance continues offline by candlelight.
- **Eternal \$0 Cost**: No monthly subscriptions, no token meters, no credit cards. Ancestral memories should not expire when a billing cycle fails.
- **Model Sovereignty**: Open weights can be fine-tuned on indigenous dialects, regional ballads, and historical computing archives without corporate censorship.

## 🛠️ Tech Stack & Architecture

- **Frontend & Runtime**: React 19, TypeScript 5.7, Vite 6
- **Styling & FX**: Tailwind CSS v4, custom CRT scanline shaders, phosphor glow filters
- **Procedural Audio**: Web Audio API pure procedural synthesizer (zero audio MP3 downloads!)
- **Physics**: HTML5 Canvas dual-bezier marigold petal gravity & drift simulation
- **Local AI Core**: Browser-native deterministic tokenization + Local Ollama HTTP daemon bridge
- **Deployment**: Vercel Global Edge Network with COOP/COEP isolation headers

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v22)
- npm or pnpm
- (Optional) [Ollama](https://ollama.com/) running locally for local Llama 3.2 inference

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-Suraj-Dhawal/ghost-in-the-machine.git
cd ghost-in-the-machine

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to commune with the spirits.

### Production Build

```bash
npm run build
npm run preview
```

## 📜 Terminal Commands Grimoire

Inside `NecroShell`:
- `help` — Reveal all forbidden commands
- `whoami` — Query your existential digital status
- `ls` — Inspect phantom registers and files
- `cat <file>` — Read cursed records (`hopper`, `ada`, `ritchie`, `turing`)
- `seance <name>` — Summon spirits of computing history
- `whisper <query>` — Commune directly with the machine
- `possessed` — Trigger a full spectral CRT glitch sequence
- `ofrenda` — Open the Día de los Muertos Living Altar
- `investigate` — Open the Paranormal IoT Telemetry Investigator
- `clear` — Purge terminal history
